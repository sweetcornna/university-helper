03:00

各睡各的

每位用户一个独立的数据库，你的课程和别人的数据分开存放。

  • 注册时自动建库：每位用户的数据放在自己的 tenant_<username> 库里，和其他用户的数据分开存放。
  • 第三方平台凭据先用 Fernet 加密再写入数据库，密钥只放在服务器的环境变量里。
  • 后端容器以非 root 用户（UID 10001）运行，根文件系统只读，Linux capabilities 全部去掉。
  • nginx 把登录接口限制在每分钟 5 次，并下发 CSP、HSTS 和 frame-ancestors 响应头。

04:30

趁天没亮，把它跑起来

一行命令装到自己的服务器上，数据也留在这台机器上。

$ curl -fsSL https://github.com/sweetcornna/university-helper/releases/latest/download/deploy_server.sh | bash -s -- -y --admin-email you@example.com
# 装好后打开 http://localhost:8080；公网访问加 --domain 你的域名 或 --host 服务器IP

脚本会生成 .env 和随机密钥，再次运行会保留原有密钥和数据。从源码部署、本地开发和 API 说明见 帮助文档。
